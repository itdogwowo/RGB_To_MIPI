# 手動佈線指引（載板 69×28 mm，4 層）
> 自動佈線結果已備份到 `docs/refs/pcb_autoroute_ugly_backup.json`，板上已清空（0 線 / 0 孔）。
## 1. 層分工
| 層 | 角色 | 內容 |
|---|---|---|
| **L1 Top** | 訊號 | 元件面、**DSI 差動對**、SPI/時鐘、短線 |
| **L2 Inner1** | **GND 整片** | 不分割、不開槽 |
| **L3 Inner2** | **3V3 整片** | 單一網路 |
| **L4 Bottom** | 訊號 | **RGB 24 條 + PCLK/DE/VSYNC** |

> Inner1 / Inner2 的鋪銅框已建好（GND@15、3V3@16），**佈線前不要勾這兩層**。

## 2. 線寬規則
| 網路類別 | 線寬 | 備註 |
|---|---|---|
| RGB 資料 / PCLK / DE / VSYNC | **6 mil** | 規則最小 5 mil |
| DSI 差動對 | **6 mil**，間距 6 mil，等長（差 < 5 mil） | 不要換層 |
| SPI / I2C / 控制 | **6 mil** | — |
| 1V8 / 1V2 / 5V | **20 mil** | 電源 |
| GND | 由 L2 平面負責 | 每個 GND 腳旁打 1 個過孔 |
| 過孔 | 鑽 12 mil / 盤 24 mil（0.3 / 0.6 mm） | — |

## 3. 建議佈線順序（由難到易）
### ① DSI 差動對（最critical，先拉）
| 網路 | 端點 |
|---|---|
| `D_CLK_P` | J1.3(8.1,10.8)  U1.7(43.4,17.6) |
| `D_CLK_N` | J1.5(8.1,10.4)  U1.8(43.0,17.6) |
| `D_DATA_P` | J1.9(8.1,9.6)  U1.1(45.8,17.6) |
| `D_DATA_N` | J1.11(8.1,9.3)  U1.2(45.4,17.6) |

**做法**：從 U1（x≈43–46）沿 L1 往左拉到 J1（x≈9.4）。兩條一組並排走，間距固定。
**不要換層**，換層會破壞阻抗。

### ② 電源（次難，但要先定型）
| 網路 | 腳數 | 端點 |
|---|---|---|
| `5V` | 4 | 20 mil 寬線；C11 / J2 / J7 / U2 |
| `1V8` | 20 | 20 mil 寬線；C12 / J1 / J2 / R10 / R11 / R2 / R28 / R3 / R5 / R6 / R7 / R9 / U2 / U4 / U5 |
| `1V2` | 10 | 20 mil 寬線；C10 / C14 / C7 / C8 / C9 / U1 / U3 |
| `3V3` | 19 | **L3 整片平面**，用過孔下到平面 |

**1V2 建議**：只有 10 個腳且全在 U1 周圍 → 在 L1 用局部鋪銅（直徑約 6 mm 的一塊）最乾淨。

## 4. 避免干擾的規則
1. **訊號不跨平面分割** — L3 是整片 3V3，不要在上面開槽
2. **3W 規則** — RGB 相鄰線間距 ≥ 18 mil（線寬 6 mil 的 3 倍）
3. **PCLK 遠離資料線** — 中間夾一條 GND 線
4. **換層處補 GND 過孔** — 訊號過孔旁 1–2 個 GND 過孔
5. **DSI 不換層**
6. **GND 腳每個都打過孔下 L2**
